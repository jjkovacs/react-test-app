# react-test-app
Built a small app to display a map of various boundaries and geographical features in the US.

* Map Component - Leaflet
* Base Map Layer - ArcGIS Streets Night
* County Data - ArcGIS USA Counties Generalized Boundaries FeatureServer
* State Data - ArcGIS USA States Generalized Boundaries FeatureServer
* Water Data - ArcGIS USA Water Bodies FeatureServer

## To Run:

Clone the repo.

Install the dependencies: `npm install`

Run the dev server: `npm start`
